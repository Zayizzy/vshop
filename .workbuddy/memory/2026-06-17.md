## 订单管理前后端联通

### 下单链路
- `OrderService.createOrder` 改为接受 `body.items` 数组（checkout 直传），cart 模式保留 fallback
- checkout 页传递完整商品信息（`goodTitle/specName/image/price`）

### Admin 订单管理
- `AdminService.getOrders` 响应新增别名 `orderNo/amount/receiver/phone/createTime`
- Admin HTML `confirmShip` → `PUT /orders/:id/status {status:'shipping', expressCompany, expressNo}`
- Admin HTML `confirmComplete` → `PUT /orders/:id/status {status:'done'}`
- 全局状态值统一：`pending → shipping → receiving → done`

### 物流同步
- Admin 录入快递 → `OrderPackage.status=2` + `expressCompany/expressNo`
- 小程序端 `GET /orders/:id` → `packages[].expressCompany/expressNo/items`

### 数据流
```
checkout POST /orders(items[]) → Order + Items + Packages
  ↓
Admin GET /api/admin/orders → 查看订单
Admin PUT /orders/:id/status {shipping + 快递} → 发货
  ↓
小程序 GET /orders/:id → packages 含物流信息
小程序 POST /orders/confirm → done
```
