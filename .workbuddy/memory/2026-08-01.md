## Admin 后台 dashboard 401 排查与修复

**现象**：登录后 `GET /api/admin/dashboard` 返回 401 Unauthorized。

**根因**：
1. 生产环境未配置 `ADMIN_ACCOUNTS` 环境变量 → 后端 `loadAdminAccounts()` 返回空数组 → 任何账号登录都返回 `{success:false}`
2. 前端 `handleLogin` 在登录失败时有**错误的离线 fallback 设计**：当 `username==='admin' && password==='123456'` 时，用假 token `local-mock-token-xxx` 伪装登录成功并调 `initDashboard()`
3. 假 token 无法通过 `AdminAuthGuard` 的 `jwtService.verifyAsync()` 校验 → 401

**错误堆栈定位**：`(匿名) @ admin/:1048` 精确指向 else fallback 分支的 `initDashboard()` 调用。

**修复**（`vshop-server/public/index.html`）：
- 移除 else 分支的 `local-mock-token` 离线 fallback，改为显示后端错误信息
- 移除 catch 分支的 `local-mock-token` fallback，改为显示网络错误提示
- 登录成功条件从 `innerData.token || innerData.success` 收紧为必须有 `innerData.token`，消除 `mock-token` 隐患

**待用户操作**：在微信云托管环境变量配置 `ADMIN_ACCOUNTS`，格式 `username:role:name:passwordHash`，hash 用 `bcrypt.hashSync(password, 10)` 生成。
